---
description: יוצר סוכן חדש מהתבנית ומחבר אותו לצוות. שימוש: /new-agent <שם> <תפקיד>
---

צור סוכן חדש לפי: $ARGUMENTS

אם חסר שם או תפקיד, שאל.

1. קרא את `templates/agent.md` ואת `CLAUDE.md`.
2. צור `.claude/agents/<name>.md` (שם באנגלית באותיות קטנות ומקפים). מלא: description קצר שמסביר מתי להפעיל, רשימת כלים **מינימלית** שהתפקיד באמת צריך, קלט, פלט (נתיב בתוך `workspace/` או תיקייה ייעודית), סדר עבודה, כללים, ומה הסוכן לא עושה.
3. אם הסוכן חוזר על עבודה, צור לו קובץ זיכרון ב-`memory/<name>-log.md`.
4. הוסף שורה לטבלת הצוות ולטבלת הניתוב ב-`CLAUDE.md`.
5. הוסף שורה ל-`docs/decisions.md`: תאריך, שם הסוכן, ולמה נוסף.
6. דווח למשתמש מה נוצר. אל תיתן לסוכן Bash או גישה לרשת אלא אם התפקיד דורש זאת, ואם כן, ציין למה.
