הרץ את הצוות עבור הבקשה הבאה:

**בקשה:** $ARGUMENTS

אם `$ARGUMENTS` ריק, שאל את המשתמש מה הנושא לפני שמתחילים.

אתה הסשן הראשי ולכן המנהל. כל שלב כותב קובץ והשלב הבא קורא אותו.

1. קרא את `CLAUDE.md` להקשר.
2. גזור slug קצר באנגלית עם מקפים. צור `workspace/briefs/<slug>.md` לפי `templates/brief.md`. מידע קריטי שחסר? רשום אותו תחת "פערים פתוחים" ושאל את המשתמש רק אם בלעדיו אי אפשר להמשיך.
3. הפעל את **researcher** עם ה-slug.
4. הפעל את **writer**.
5. הפעל את **editor**.
6. אם נשארו placeholders של תמונות או `[צריך מקור]`, דווח עליהם במפורש במקום להעלים.
7. סכם למשתמש: רשימת הקבצים שנוצרו, ומה פתוח.

בין שלבים מסור לסוכן הבא רק את ה-slug ואת נתיבי הקבצים. אל תפרסם ואל תשלח כלום החוצה.
