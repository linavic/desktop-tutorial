description: מריץ את כל השרשרת של צוות התוכן: מנהל, חוקר, כותב, עורך, מפיץ
---

הרץ את צוות יצירת התוכן מקצה לקצה עבור הבקשה הבאה:

**בקשת התוכן:** $ARGUMENTS

אתה הסשן הראשי ולכן המנהל-על. הרץ את הסוכנים לפי הסדר, כשכל שלב כותב קובץ והשלב הבא קורא אותו:

1. קרא את `CLAUDE.md` להקשר (תחום, טון, קהל).
2. הפעל את **orchestrator** עם בקשת התוכן → slug ובריף ב-`content/briefs/<slug>.md`.
3. הפעל את **researcher** עם ה-slug → `content/research/<slug>.md`.
4. הפעל את **writer** → `content/drafts/<slug>.md`.
5. הפעל את **editor** → `content/final/<slug>.md`.
6. הפעל את **publisher** → `content/final/<slug>.distribution.md`.

בין שלב לשלב מסור לסוכן הבא את ה-slug ואת נתיבי הקבצים הרלוונטיים.
בסיום, סכם למשתמש את כל הקבצים שנוצרו.

אם `$ARGUMENTS` ריק, שאל מה הנושא לפני שמתחילים. אל תפרסם כלום.
