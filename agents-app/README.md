# סוכני Etel Clinic

אפליקציית ווב שמריצה 5 סוכנים בשרשרת ומציגה מה כל אחד עושה בכל שלב.

## הרצה
```
cd agents-app
node server.js                         # מצב הדגמה, בלי מפתח
OPENAI_API_KEY=... node server.js      # מצב חי עם OpenAI
ANTHROPIC_API_KEY=... node server.js   # מצב חי עם Claude
```
אפשר גם להדביק את המפתח ישירות בדף, בחלק "הגדרות מפתח API" (בחירת ספק, מפתח ומודל). המפתח נשלח לשרת רק בזמן הרצה ולא נשמר שם.

פותחים http://localhost:3000. אם שני המפתחות מוגדרים, OpenAI קודם (`PROVIDER=anthropic` מכריח Claude).
מודל: `OPENAI_MODEL` (ברירת מחדל `gpt-4.1`) או `CLAUDE_MODEL`. פורט: `PORT`.

## סיסמת כניסה
- בלי `APP_PASSWORD` השרת מאזין רק ל-`localhost` ואי אפשר להגיע אליו מהרשת.
- עם `APP_PASSWORD=סיסמה_ארוכה node server.js` השרת נפתח לרשת ודורש התחברות. אחרי 5 ניסיונות שגויים יש נעילה של 15 דקות.
- `APP_SECRET` (לא חובה) מקבע את חתימת ההתחברות בין הפעלות. בלעדיו, הפעלה מחדש של השרת מנתקת את כולם.
- חשוב להריץ מאחורי HTTPS (למשל Render או Railway), כדי שהסיסמה והמפתח לא יעברו גלויים.

## פריסה ל-Render
הקובץ `render.yaml` בשורש הריפו מגדיר שירות. ב-Render: New → Blueprint → בוחרים את הריפו → מזינים `APP_PASSWORD` → Apply. הקישור יופיע בלוח הבקרה.

## הסוכנים
1. **אסטרטגית:** קוראת את `../CLINIC.md`, בוחרת זווית, קהל וקריאה לפעולה.
2. **כותבת:** כותבת את הפוסט בעברית לפי הכללים.
3. **מתאימה לרוסית:** גרסה רוסית טבעית.
4. **בודקת ציות:** 6 בדיקות דטרמיניסטיות (שורות עבריות, קישורים, מחירים, הבטחות, האשטגים), ומתקנת אם צריך.
5. **מתזמנת:** בוחרת מועד (ראשון עד חמישי, לא שבת) ומרכיבה חבילה. **לא מפרסמת בעצמה.**

## הערות
- במצב הדגמה הטקסטים קבועים ולדוגמה בלבד. רק מצב חי כותב טקסט לפי הנושא.
- מפתח ה-API נשאר בשרת ולא נשלח לדפדפן.
