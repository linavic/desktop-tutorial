# מרכז שליטה: צוות 8 הסוכנים

אפליקציית ווב שבה מקלידים משימה, והסוכנים עובדים בשרשרת בזמן אמת. רואים מי עובד עכשיו, מה הוא קיבל ומי העביר לו, מה הוא כותב ומה הוא מעביר הלאה.

הסוכנים נטענים מקבצי ההגדרה המקוריים שלך ב-`agents/*.md` (הועתקו מ-`5-agents`). ההעברה ביניהם נעשית דרך קבצים. כל ריצה נשמרת ב-`runs/<runId>/` (לא נכנס ל-git).

## הזרימה
```
מנהל → חן → חוקר → כותב → יעל → יובל → עורך → מפיץ
בריף   מקורות  מחקר   טיוטה   שכתוב  תמונות  סופי    הפצה
```
| סוכן | מקבל | מוציא |
|---|---|---|
| מנהל | בקשת המשתמש | `content/briefs/<slug>.md` |
| חן | בריף | `content/sources/<slug>.md` |
| חוקר | בריף + מקורות | `content/research/<slug>.md` |
| כותב | בריף + מחקר + מקורות | `content/drafts/<slug>.md` |
| יעל | הטיוטה | `Output/<slug>.md` (עם `{{IMAGE_NEEDED}}`) |
| יובל | הטקסט של יעל | `yuval/outputs/<slug>.md` + תמונות |
| עורך | הטקסט של יעל עם התמונות + בריף + מחקר | `content/final/<slug>.md` |
| מפיץ | הגרסה הסופית | `content/final/<slug>.distribution.md` |

כמו ב-`CLAUDE.md` שלך, יובל מקבל את ה-placeholders של יעל ומייצר תמונה לכל אחד, והשרת מחליף אותם בהפניות לתמונות לפני שהטקסט עובר לעורך. "ראובן" (הסשן הראשי) הוא כאן השרת.

## הרצה
```
cd agents-app
node server.js                         # מצב הדגמה, בלי מפתח
OPENAI_API_KEY=... node server.js      # מצב חי עם OpenAI
ANTHROPIC_API_KEY=... node server.js   # מצב חי עם Claude
```
פותחים http://localhost:3000. אפשר גם להדביק את המפתח בדף ("הגדרות") ולבחור ספק ומודל.
- אם שני המפתחות מוגדרים, OpenAI קודם (`PROVIDER=anthropic` מכריח Claude).
- מודל: `OPENAI_MODEL` (ברירת מחדל `gpt-4.1`) או `CLAUDE_MODEL`. פורט: `PORT`.

## מה רואים במסך
- **שורת משימה** ודוגמאות מוכנות.
- **שרשרת הסוכנים:** צומת לכל סוכן עם אייקון, טבעת מסתובבת כשהוא עובד, וי כשסיים. בין הצמתים קו שבו עוברת נקודת אור עם שם הקובץ שמועבר.
- **כרטיס הסוכן הפעיל:** תפקיד, כלים בהגדרה, מי העביר לו ולמי הוא מעביר, רשימת צעדים מקובץ ההגדרה, ופלט חי שנכתב בסטרימינג. אצל יובל גם גלריית התמונות.
- **יומן פעילות** עם שעה, סוכן ופעולה.
- **תוצרים:** לשונית לכל קובץ, העתקה והורדת הכול.

## מגבלות (חשוב)
- **הסוכנים כאן הם קריאות למודל עם ההגדרה של כל סוכן כ-system prompt.** אין להם גישה למערכת קבצים, לאינטרנט או לכלים.
  - **חן והחוקר לא מחפשים באינטרנט.** חן מחזירה מילות חיפוש וסוגי מקורות בלבד, מסומנים "לא אומת", ולא כתובות.
  - **יעל** מחזירה Markdown בלבד, בלי קובץ HTML.
  - ב-Claude Code האמיתי הסוכנים האלה כן משתמשים ב-WebSearch וב-Read/Write/Bash.
- **תמונות:** יובל יוצר תמונות אמיתיות רק עם מפתח OpenAI (המודל `gpt-image-2`, 1024x1024, איכות medium, כמו בסקיל `gpt-image-gen`). עד 2 תמונות לריצה, ולכל תמונה יש עלות ב-OpenAI. עם Claude בלבד נוצרים prompts בלי תמונות. אין תיקיית reference בסביבה, אז הסגנון הוא ברירת מחדל נקייה.
- **רשימת הצעדים בכרטיס** מסומנת כשהסוכן מסיים. מה שמתקדם בזמן אמת הוא הפלט המוזרם.
- **המפיץ לא מפרסם בפועל.** הוא מכין התאמות וצ'קליסט.
- **במצב הדגמה** הטקסטים קבועים ולא תלויים במשימה, והתמונות הן איורי SVG.
- **מצב חי נבדק מול שרת מדומה בלבד**, לא מול OpenAI או Claude אמיתיים.

## סיסמת כניסה
- בלי `APP_PASSWORD` השרת מאזין רק ל-`localhost`.
- עם `APP_PASSWORD=סיסמה_ארוכה node server.js` השרת נפתח לרשת ודורש התחברות. אחרי 5 ניסיונות שגויים יש נעילה של 15 דקות.
- `APP_SECRET` (לא חובה) מקבע את חתימת ההתחברות בין הפעלות.
- להריץ מאחורי HTTPS (למשל Render), כדי שהסיסמה והמפתח לא יעברו גלויים.

## פריסה ל-Render
`render.yaml` בשורש הריפו מגדיר שירות. ב-Render: New → Blueprint → הריפו → מזינים `APP_PASSWORD` → Apply.

## הקשר הפרויקט
במקום `CLAUDE.md` (ששם תחום וטון הם placeholders), הסוכנים מקבלים את `../CLINIC.md` כברירת מחדל. אפשר לדרוס אותו בשדה "הקשר הפרויקט" בהגדרות.
