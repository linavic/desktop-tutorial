# מרכז שליטה: צוות 5 הסוכנים

אפליקציית ווב שבה מקלידים משימה, והחמישה עובדים בשרשרת בזמן אמת: מנהל, חוקר, כותב, עורך, מפיץ. רואים מי עובד עכשיו, מה הוא קיבל, מה הוא כותב ומה הוא מעביר הלאה.

הסוכנים נטענים מקבצי ההגדרה המקוריים שלך ב-`agents/*.md` (הועתקו מ-`5-agents`). ההעברה ביניהם נעשית דרך קבצים, כמו ב-`CLAUDE.md` שלך: `content/briefs → research → drafts → final`. כל ריצה נשמרת ב-`runs/<runId>/content/` (לא נכנס ל-git).

## הרצה
```
cd agents-app
node server.js                         # מצב הדגמה, בלי מפתח
OPENAI_API_KEY=... node server.js      # מצב חי עם OpenAI
ANTHROPIC_API_KEY=... node server.js   # מצב חי עם Claude
```
פותחים http://localhost:3000. אפשר גם להדביק את המפתח בדף עצמו ("הגדרות") ולבחור ספק ומודל.
- אם שני המפתחות מוגדרים, OpenAI קודם (`PROVIDER=anthropic` מכריח Claude).
- מודל: `OPENAI_MODEL` (ברירת מחדל `gpt-4.1`) או `CLAUDE_MODEL`. פורט: `PORT`.

## מה רואים במסך
- **שורת משימה** ודוגמאות מוכנות.
- **שרשרת הסוכנים:** צומת לכל סוכן עם אייקון, טבעת מסתובבת כשהוא עובד, וי כשסיים. בין הצמתים קו שבו עוברת נקודת אור עם שם הקובץ שמועבר.
- **כרטיס הסוכן הפעיל:** תפקיד, כלים בהגדרה, קבצי קלט ופלט, רשימת צעדים מקובץ ההגדרה שלו, ופלט חי שנכתב בסטרימינג.
- **יומן פעילות** עם שעה, סוכן ופעולה.
- **תוצרים:** לשונית לכל קובץ, העתקה והורדת הכול.

## מגבלות (חשוב)
- **הסוכנים כאן הם קריאות למודל עם ההגדרה של כל סוכן כ-system prompt.** אין להם גישה למערכת קבצים, לאינטרנט או לכלים. החוקר לא מחפש באינטרנט, ומסמן "צריך אימות" במקום להמציא מקורות. ב-Claude Code האמיתי הסוכנים האלה כן משתמשים ב-WebSearch וב-Read/Write.
- **רשימת הצעדים בכרטיס** היא מקובץ ההגדרה. היא מסומנת כשהסוכן מסיים, ולא תוך כדי עבודה. מה שמתקדם בזמן אמת הוא הפלט המוזרם.
- **המפיץ לא מפרסם בפועל.** הוא מכין התאמות וצ'קליסט.
- **יעל, יובל וחן** מהריפו המקורי לא כלולים. זו השרשרת של חמשת הסוכנים בלבד.
- במצב הדגמה הטקסטים קבועים ולא תלויים במשימה.

## סיסמת כניסה
- בלי `APP_PASSWORD` השרת מאזין רק ל-`localhost`.
- עם `APP_PASSWORD=סיסמה_ארוכה node server.js` השרת נפתח לרשת ודורש התחברות. אחרי 5 ניסיונות שגויים יש נעילה של 15 דקות.
- `APP_SECRET` (לא חובה) מקבע את חתימת ההתחברות בין הפעלות.
- להריץ מאחורי HTTPS (למשל Render), כדי שהסיסמה והמפתח לא יעברו גלויים.

## פריסה ל-Render
`render.yaml` בשורש הריפו מגדיר שירות. ב-Render: New → Blueprint → הריפו → מזינים `APP_PASSWORD` → Apply.

## הקשר הפרויקט
במקום `CLAUDE.md` (ששם תחום וטון הם placeholders), הסוכנים מקבלים את `../CLINIC.md` כברירת מחדל. אפשר לדרוס אותו בשדה "הקשר הפרויקט" בהגדרות.
